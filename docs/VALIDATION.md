## Limits of these checks

The Windows commands are documented but were not run on Windows here. Local sockets are unavailable in the preparation environment, so notebook cells were executed directly through IPython rather than through a running JupyterLab server. A JupyterLab browser session and GitHub's own notebook renderer were not tested here. The GitHub Actions workflow has not yet run on GitHub.

The existing tests cover stated identities and numerical cases; they are not an independent model validation or proof of live investment performance. See `METHODOLOGY.md` for the study's scope.

## Reproduce the checks

From the project root, using the Python environment described in [RUNNING.md](RUNNING.md):

```bash
python -m unittest discover -s tests -v
python run_analysis.py
```

Then open the notebook, restart its kernel and run all cells. Running the calculation replaces the generated outputs. Fixed input files are listed with their original hashes in [ORIGINAL_FILES.json](ORIGINAL_FILES.json).
